# নয়ন মন্ডল (Nayan Mondol) - Portfolio Website & Node.js Backend

A modern, responsive, high-performance personal portfolio and pharmacy management application built with **React**, **TypeScript**, **Tailwind CSS**, and a full-stack **Node.js / Express** backend.

---

## 🌟 Features

- **Full-Stack Node.js & Express API:**
  - `/api/health`: Server health checks, Node version, and uptime monitoring.
  - `/api/profile`: Professional bio, contact data, experience details.
  - `/api/contact`: Direct contact inquiry handling with live server responses.
  - `/api/consultations`: Pharmacy consultation and appointment booking API.
  - `/api/drug-checker`: Instant Bangladesh medication guidance and interaction safety checker (Napa, Seclo, Comet, Camlod, Zimax, etc.).

- **Frontend Experience:**
  - Modern bilingual interface (Bengali & English toggle).
  - Pharmacy & Medical executive profile (Sales Executive & Pharmacist since 2017).
  - Interactive dosage guide and 24-hour color-coded medication routines.
  - BMI and health calculator widgets.
  - Fully responsive for mobile, tablet, and desktop viewports.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.0.0 or higher, tested with Node 22+)
- npm or bun

### Installation

```bash
# Clone the repository
git clone https://github.com/nayangemini430/nayan-mondol-portfolio.git

# Navigate into the project folder
cd nayan-mondol-portfolio

# Install dependencies
npm install
```

### Running Locally

```bash
# Start the full-stack development server
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

```bash
# Build the client app
npm run build

# Start the Node.js production server
npm start
```
